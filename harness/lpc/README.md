# P03 LPC compiler slice

Source: [Universal LPC Character Generator](https://github.com/sanderfrenken/Universal-LPC-Spritesheet-Character-Generator), commit `675e21e04aaff8486a3a24e09573b3d5af9d28b9`. `s01_p03_slice.json` is the approved selection. `catalog_v1.json` records stable IDs, compatibility, palette/color matching, direction/clip facts, dimensions, SHA-256, credit provenance and legal/technical status. Only the verified male appearance and selected palette variants are currently accepted. Other catalog combinations require compilation/verification; absence never means compatibility.

Rebuild with `bash scripts/lpc/bake_slice.sh --fetch`. This fetches the exact pinned commit (partial clone in ignored `.tools/lpc-upstream`), parses definition/palette/credit data, verifies source bounds and bakes `game/data/lpc/catalog_v1.res` with Godot 4.7.2. Without network, pass `--source <existing-upstream-checkout>` instead. The compiler does **not** execute upstream JavaScript or incorporate generator code. Source registry hashes are recorded; mechanically extracted row/frame facts drive our own implementation. `upstream_slice/` preserves only nine source PNGs, selected definitions/palettes/credits and the asset license. The runtime package contains the catalog plus compressed PNG bytes, so an exported project has no dependency on `harness/` or filesystem paths outside `game/`.

Runtime: stable IDs → normalized appearance key → compatibility/semantic resolver → z-sorted CPU composition → bounded shared clip cache → one Sprite3D. Idle explicitly uses the walk standing pose. Run/Dodge fall back to Move and Hurt/unknown actions to Idle; no claim of upstream clip availability is inferred from names alone. Walk is 64 px; sword slash composes centered body layers into 192 px frames. The same pivot formula supports 128 px. The foot anchor remains `(frame_size/2, frame_size/2 + 28)` while physics stays at CharacterBody feet. Textures are composed/uploaded on appearance changes, never per animation frame. Equipment weapon visuals participate in the cache key; save files contain only appearance configuration.

## Asset attribution and redistribution

All selected art is redistributed under the available **CC BY-SA 3.0** license option. Full original attribution, source URLs, authors, notes and offered licenses are preserved in `upstream_slice/CREDITS-selected.csv`, each definition's credits and the runtime catalog. Full selected license: `upstream_slice/cc-by-sa-3_0.txt`. No upstream asset license is replaced by the repository code license. This slice's asset modifications are selection, atlas cropping/centering, layer composition and packaging; resulting composed art remains CC BY-SA 3.0. Distribution of the game must retain these credits, license and source information (also bundled in runtime catalog); final credits UI is not P03 scope.
