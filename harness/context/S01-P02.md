# S01-P02 — World Foundation

## Objective

A real save enters a deterministic, smooth volumetric island through production Main; terrain streams and a local edit survives reload.

## Scope

- In: pinned Voxel Tools behind Black Island-owned interfaces; smooth SDF terrain, local density/material editing, collision update and chunk-border continuity.
- In: deterministic beach/plains/hills/forest-region island data, buildable spawn area, ocean/basic generated-water hook, horizon/fail-safe/soft-boundary proof.
- In: coordinate utilities, sparse vertical streaming, profiling counters, seed/version + terrain/material deltas, separate BuildGrid coordinate/occupancy/shared-edge seam.
- Out: full dynamic hydrology, final props/foliage, farming, LPC/player combat/inventory, mobs/NPCs, caves and full construction/support. A debug pawn/camera may inspect terrain until P03.
- Expected files/subsystems: `game/scripts/world/`, world resources/scenes, save integration, debug instrumentation and coordinate/persistence tests.

## Dependencies and required references

- Requires validated/pushed P01 and a real Boot/SaveSelect/Main path; start an implementation branch from that checkpoint.
- Read `AGENTS.md`, `harness/prompts/S01-P02-world-foundation.md`, `PLANS.md`, `docs/architecture/VOXEL_WORLD_IMPLEMENTATION.md`, `WORLD_STREAMING.md`, `WATER_AND_HYDROLOGY.md`, `SAVE_AND_MIGRATION.md` (all under `docs/architecture/`), `docs/design/BIOMES_AND_PROP_GENERATION.md`, ADR-0004 (`docs/decisions/ADR-0004-smooth-voxel-world-and-build-grid.md`) and `research/VOXEL_TOOLS_INTEGRATION.md`.
- Then inspect only relevant implementation. Reuse P00 validated pins and extension/mobile risk evidence.

## Acceptance criteria

1. Smooth SDF terrain uses the selected Voxel Tools route behind replaceable project interfaces. Prove local density/material edits, collision update and both sides of chunk-border continuity.
2. Scale stays `TerrainVoxel = 0.5 m`, `BuildCell = 1 m`, `WorldChunk = 64 x 64 x 64 m`; WorldChunk is a sparse address/persistence unit subdivided into internal data/mesh blocks, not one dense allocation.
3. Tested world/voxel/chunk/BuildGrid conversions handle positive/negative coordinates, boundaries and vertical chunk addresses.
4. A 3x3 horizontal near ring streams only required vertical regions; workers prepare data, main-thread work applies SceneTree/resources; hysteresis prevents boundary thrash. Unload/reload preserves state without duplication/loss.
5. Same seed reproduces sampled terrain/materials; different seeds meaningfully differ. At least sand, grass and dirt/stone exist; bounded paint updates only affected regions/neighbors.
6. Save seed/generation version + local terrain/material delta survive reload; generated meshes/collision buffers are not save authority.
7. BuildGrid debug targeting/shared-edge seam, ocean/water hook and horizon/fail-safe/soft-boundary proof work through Main without implementing later systems.
8. Record generation/load/unload/remesh/collision latency, loaded chunk count, memory where available and border-crossing frame times. Label non-device measurements `desktop proxy only`.
9. P01 boot/save regressions pass. Record commands/results/seed in `harness/build/S01-P02.md`; inspect secrets/local paths, commit/push and hand off before P03.

## Checkpoints

- C01: dependency/smooth-voxel integration + coordinate tests.
- C02: deterministic island + 3x3/vertical streaming + local material paint.
- C03: delta persistence + BuildGrid seam + ocean/boundary + profiling/handoff.
- Current state: not implemented; gated by validated P01.

## Risks

- GDExtension desktop load does not establish Android/iOS export or mobile thermal/frame-time budgets; retain the module/custom-build fallback behind the same interfaces.
- Do not expand beyond the near ring or serialize dense untouched world data without measured budgets.
- If the pinned route fails a required gate, capture a minimal reproducer and evidence-driven decision; do not silently invent a voxel engine or restore superseded heightmap architecture.
