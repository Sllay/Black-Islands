# S01-P04 — Ecology / Gameplay Surface

## Objective

Complete an integrated Season 1 slice: create/load save -> smooth island -> player -> harvest/farm/build/fight -> loot/container -> save/reload, within one running build.

## Scope

- In: deterministic biome props for beach/plains/hills/forest; local foliage suppression/regrowth; shared generic harvesting for tree, rock and corpse.
- In: one dedicated FarmPlot/crop loop; Foundation/Wall/Ceiling/Pillar with occupancy/support provenance; chest transfers through authoritative transactions.
- In: shared passive/neutral/aggressive mob framework, corpse delicate/harvest channels, protected death/drop bags, offscreen identity-preserving simulation seam and save integration.
- In: integrated SeasonTest with collapsible debug instrumentation; opening survivors/intro only if required systems leave scope available.
- Out: full village social AI, caves, full crop/tool/structure/mob catalogs, full weather/lightning, complete workstation/craft-queue UX, full weapon/Skill/Ultimate content and multiplayer/tribes.
- Expected files/subsystems: world props/foliage, farming/building/inventory/combat/mob state and adapters, data/resources, save hooks, SeasonTest and anti-exploit tests.

## Acceptance criteria

1. Data-driven biome/slope/material/height/water/density/rarity/persistence rules produce stable resource spawn IDs. Batch repeated visuals; do not allocate heavy physics/AI per grass blade. Streaming does not reshuffle harvested persistent props.
2. Foundation/path/FarmPlot suppress eligible foliage locally, excavation invalidates unsupported foliage and demolition/removal permits eligible regrowth. Follow cutout/alpha-scissor + mipmap/coverage direction where applicable.
3. Generic harvesting clamps actual damage to remaining harvest health, derives finite yield from actual fraction/tool quality/affinity and never makes reserves negative or duplicates overkill output. Demonstrate different tools on tree, rock and corpse; outputs use transaction APIs.
4. Hoe creates a dedicated dry FarmPlot without removing terrain density; plant/water/grow/harvest one crop. Plot stores moisture/growth/seed/fertilizer/decay seams, supports approximately one-day watering, dry-empty decay and definition-driven returns; removing support breaks it. Rain may remain an event seam.
5. Foundation/Ceiling occupy cells, Wall owns one shared edge and Pillar a point/center socket. True roots permit up to two horizontal ceiling cells; floating pieces never reset root distance. Alternate roots preserve supported subsets; only unsupported subsets collapse. Material tier changes durability, not reach.
6. Player/chest full/partial transfers use revisions and atomic multi-inventory ownership commits; UI never independently mutates both inventories. Stress-test ordering and reject stale commands without duplication/loss.
7. Shared mob framework proves passive flee/defend, neutral contextual aggression with warning and aggressive perception/day-night seam. Preserve authoritative identity through ACTIVE/NEAR_PROXY/REGIONAL/STASIS; deactivate costly distant presentation/AI and restore once.
8. Alive -> death -> CorpseState supports delicate loot and tool harvest; disappearance/decomposition atomically transfers protected loot to DeathBagInventory. Generic WorldDropBag packages avoid one physics object per stack.
9. Persist implemented props, plots, structures, containers, mob state and protected bags; do not save foliage instance buffers/navigation caches. SeasonTest demonstrates all required loops and representative save/reload in the same build.
10. Regressions cover overkill/reserves, chest transfer races, corpse/bag conversion, foliage regrowth, shared-edge uniqueness, false support resets/alternate roots, unsupported plots, resource/mob stream identity and all P01-P03 paths.
11. Record prop/foliage counts and draw strategy, active mobs, streaming frame times, transaction stress count, support recompute size/time and save-size changes in `harness/build/S01-P04.md`. Label desktop proxies; review diff/secrets/local paths, commit/push and hand off with Season 1 readiness/deferred Season 2 items.

## Risks

- Broad scope must preserve the required integrated loop; defer optional intro/full weather/full catalogs before weakening transaction/support/identity invariants.
- LimboAI/HSM is used if already introduced/validated; behavior execution remains replaceable/data-driven.
- Desktop/headless measurements do not prove mobile sustained performance, touch UX or export capability; record those gates separately.
- Final opaque placeholder foliage is batched but adds draw/vertex cost; native streaming/harvest hitches remain desktop proxy findings. Direct-steering mob navigation, huge population scheduling and large connected support components still need device budgets. Preserve all P03/P02 terrain settings during later validation.
