# C03 representative weapon visual

`test_blade.svg` is an original geometric placeholder created for Black Island's detached-weapon proof. It is not copied from the Universal LPC spritesheets and is not final production art.

The LPC_LAYER example uses the existing accepted LPC catalog asset. Its original IDs, source and licensing/credits metadata remain in the LPC pipeline and `harness/lpc/upstream_slice/CREDITS-selected.csv`; this folder does not replace those records.
