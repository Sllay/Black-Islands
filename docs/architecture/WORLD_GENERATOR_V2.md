# Chapter1 native world generation

Generation2/profile `chapter1_native_960m_v2` is versioned in `game/data/world/chapter1_v2.json`. New frontend worlds select it; existing generation1/profile `chapter1_iteration_480m_v1` keeps the original deterministic math. Unsupported generation/profile pairs are rejected before loading. R1 PlayerProfile/WorldSave schemas2, terrain index/chunk/density codec schemas1 remain unchanged.

WorldGenerationProfile -> WorldFieldV2 -> NativeTerrainGraph -> actual VoxelGeneratorGraph assigned to VoxelLodTerrain. Macro coastline/domain warp, plateaus/lowlands and hydrology carving execute natively for base blocks. GDScript chooses seed-driven hydrology and village candidates. Native series-baked2D lookup supports immutable metadata; sparse authoritative density probes evaluate native SDF exactly. No production per-voxel GDScript base loop. XZ caching, subdivision, optimized execution map and native Smoothstep nodes are used. The v1 compatibility QA generator also delegates its base blocks natively.

VoxelDeltaStream returns NOT_FOUND for untouched blocks so Voxel Tools invokes its native graph. For an edited block it generates native base and overlays only project-owned sparse deltas, including aligned coarser samples. It never saves generated/mesh buffers as another authority. Godot's SDF16 buffer API already converts physical voxel distances; legacy ±8voxel-unit clamp is retained rather than silently applying a new codec or clipping sentinel. Native instancer can use series generation because terrain.generator is the graph itself.

Profile envelope960×850m, voxel.5m/build cell1m/logical chunk64m, lowland baseline8m, elevation step6m. Natural levels0..4 with smooth ramps/plateaus; +5/+6 reserved. Deep ocean descends to-120m (-20levels). Sampled land area~0.60–0.61km² (~4× prototype envelope), broad lowlands~69–73%. Geometry size and parameters live in profile data. Material ownership uses graph splat weights; logical biomes/prop seeds remain project-owned/versioned.

Lakes1–2 per seed, variable center/radii/shore noise, flat-ish basin floor + smooth irregular banks. River selection follows native macro descent high->low->sea; no fixed lake coordinate. WorldWater and GeneratedWaterView derive sleeping bodies from the same metadata (no flow solver). Village candidate metadata evaluates a40×40m sampled footprint, contiguous eligible cells, slope, water/coast access and flood risk; no village is spawned.
