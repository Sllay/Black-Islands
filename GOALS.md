# Black Island — Goals

## Product goal

Ship Chapter 1 as a compact but real vertical slice of a mobile-first 2.5D life/farming RPG, village-management game and fluid action RPG.

## Core player fantasy

The player arrives mysteriously on a procedurally generated island, saves survivors, becomes responsible for a recovering village, farms/builds/crafts, forms deep relationships and explores dangerous multi-floor mines.

## Chapter 1 target loop

Create save -> customize character -> generate island -> intro attack -> save village -> gather/craft/farm/build -> manage relationships/jobs -> sleep/progress -> unlock mine -> explore/ fight/rescue -> return and improve village.

## Pillars

1. Playable from the foundation, not backend-first.
2. Mobile UX and performance are first-class constraints.
3. Fluid readable combat with telegraphed enemy attacks.
4. NPCs feel socially alive while remaining fully functional offline.
5. Procedural generation is design-constrained, not random noise soup.
6. Producer-facing content tools minimize script editing for new content.
7. State is persistent and data-driven so worlds can stream safely.

## Chapter 1 content ceiling

- Village population target: up to 10 meaningful NPCs.
- Start with approximately 3 live survivors; more are rescued/recruited.
- One medium island per save.
- Mine progression demonstrates multiple floors and at least one meaningful biome/progression transition.
- Enough weapons/items/building/farming content to prove the systems; breadth comes after the vertical slice.

## Non-goals for the first vertical slice

- Fully realized public multiplayer service.
- Unlimited procedural NPC population.
- LLM-required gameplay.
- Every planned mine biome/floor.
- Final art volume.
- A bespoke voxel engine.
